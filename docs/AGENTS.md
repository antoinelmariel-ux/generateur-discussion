# AGENTS.md — Become the boss of ethical interactions with HCPs

## Description du projet

Become the boss of ethical interactions with HCPs est une SPA locale destinée à animer des discussions autour de principes éthiques appliqués à des activités impliquant des professionnels de santé.

## Stack

- HTML5
- CSS3
- JavaScript vanilla
- Données JSON
- Aucun backend
- Aucune dépendance obligatoire

## Commandes utiles

Aucune commande de build n’est nécessaire.

Pour tester :
- ouvrir `index.html` dans un navigateur moderne ;
- tester le parcours Jeu ;
- tester l’import/export JSON dans le Backoffice ;
- vérifier la console navigateur.

## Conventions

- Code JavaScript lisible et explicite.
- Variables et fonctions en anglais.
- Libellés visibles en français.
- Données structurées selon le modèle AppConfig.
- Ne pas ajouter de dépendance sans justification.

## Règles de sécurité

- Ne supprimer aucun fichier sans validation.
- Ne pas ajouter de backend.
- Ne pas ajouter de tracking.
- Ne pas collecter de données personnelles.
- Ne pas modifier le périmètre fonctionnel sans validation.

## Done when

La V1 est terminée lorsque le jeu fonctionne, que les paires ne se répètent pas pendant une session, que les implications expertes s’affichent, que le backoffice permet l’import/export JSON et que les tests manuels principaux sont validés.

## À ne pas modifier sans validation

- Structure du modèle JSON.
- Périmètre fonctionnel V1.
- Choix de stack sans dépendance.
